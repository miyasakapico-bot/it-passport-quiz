# 🍎 ぽふりんのITパスポート4択クイズ

ITパスポート試験に登場する用語を、説明文から4択で答えて反復学習する静的Webアプリです。英語の略語だけでなく、日本語の専門用語も収録しています。

公開ページ: <https://miyasakapico-bot.github.io/it-passport-quiz/>

HTML・CSS・JavaScriptだけで動作し、サーバー、データベース、外部API、ログイン、広告、アクセス解析は使用していません。学習履歴はブラウザの `localStorage` にだけ保存されます。

## 主な機能

- 問題と選択肢を毎回ランダム表示
- 回答後に正誤、正解、短いオリジナル解説を表示
- 略語は英語の正式名称と日本語の意味も解説
- 「わからない」ボタンと、間違えた問題の苦手登録
- 誤答した問題は同じセッションで別の5問を挟んで再出題
- 「これまでの問題」「今回追加した問題」「追加範囲②（13～15章）」「すべての問題」の4つから出題範囲を選択
- 選んだ範囲の中で、全問題、ランダム10問、ランダム20問、苦手問題のみ、カテゴリー別の5モードを利用可能
- 正解数、出題数、正答率、連続正解数を表示
- 問題ごとの正解回数、不正解回数、最終回答日時を端末内に保存
- 苦手問題の一覧、個別解除、全履歴リセット
- キーボードの `1`〜`4` で回答可能
- スマートフォンとパソコンに対応したレスポンシブデザイン
- 色だけでなく `✓`、`✕`、文章でも正誤を案内

## 使い方

インストールやビルドは不要です。`index.html` をブラウザで開くか、このフォルダーで簡易Webサーバーを起動してください。

```bash
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開きます。

## 新しい問題の追加方法

問題データは [questions.js](questions.js) だけにまとめています。ファイル末尾の配列内へ、次の形で1問ずつ追加してください。

```js
{
  id: "add-20260802-er-diagram",
  batchId: "addition-2026-08-02-ch13-15",
  category: "データベース",
  question: "業務で扱う実体と、それらの関係を図で表すデータモデルはどれか。",
  answer: "E-R図",
  choices: ["E-R図", "DFD", "フローチャート", "状態遷移図"],
  explanation: "E-R図はEntity-Relationship Diagramの略。実体と関連を表す。"
}
```

追加時の注意点は次のとおりです。

1. `id` は半角英数字とハイフンで、ほかの問題と重複しない名前にします。
2. 第13～15章の追加範囲②として扱う問題には `batchId: "addition-2026-08-02-ch13-15"` を付けます。既存108問と追加範囲①の61問は変更しません。
3. `category` は既存のカテゴリー名に合わせます。新しい名前にすると、カテゴリー選択にも自動で追加されます。
4. `question` は正解用語そのものを書かず、答えが一つに決まる説明文にします。
5. `choices` は必ず異なる4用語にし、`answer` と同じ用語をちょうど1回入れます。
6. 誤答候補には、できるだけ意味が似ていて混同しやすい用語を入れます。
7. 略語の `explanation` には、英語の正式名称と日本語の意味を含めます。
8. 一つ前の問題オブジェクトとの間にカンマ `,` が必要です。

追加後は、次の検証を実行してください。

```bash
node validate.js
```

## 自動検証

`validate.js` は次を機械的に確認します。

- 問題IDが重複していない
- 全問題に4つの選択肢がある
- 選択肢内に重複がない
- 正解が選択肢に1回だけ含まれる
- 必須項目が空欄ではない
- 指定された全用語が正解として登録されている
- 既存108問・追加範囲①の61問・追加範囲②の96問が `batchId` で正しく分離されている
- 第13～15章の指定96用語が1問ずつ登録されている
- 追加問題の問題文に正解用語が直接書かれていない
- 正解・不正解・連続正解用のぽふりん台詞が登録されている
- 追加範囲②のデータ上の正解位置が均等で、表示時にも選択肢をランダム化する
- 既存の `localStorage` キーが維持されている
- 既存の履歴形式と、苦手問題を5問後に復習登録する処理が維持されている
- RFPとNDAが1問ずつだけ登録されている
- `questions.js`、`app.js`、`validate.js` にJavaScript構文エラーがない

## ファイル構成

```text
.
├── index.html      # 画面構造
├── styles.css      # デザイン、スマートフォン対応
├── app.js          # クイズ、再出題、履歴保存の処理
├── questions.js    # 問題データ（問題追加はここ）
├── validate.js     # 問題データと構文の検証
├── assets/         # ぽふりんの表情画像
└── README.md       # この説明
```

## プライバシー

回答履歴は利用中のブラウザ内にだけ保存されます。外部サーバーへの送信はありません。ブラウザのデータを消すか、アプリ内の「全履歴をリセット」を実行すると履歴は削除されます。
